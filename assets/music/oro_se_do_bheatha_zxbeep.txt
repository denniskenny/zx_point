================================================================================
 Óró Sé do Bheatha 'Bhaile — ZXBeep / Tritone arrangement (Title screen)
================================================================================

WHAT THIS IS
------------
"ZXBeep" is not a single file format — it is the family of 1-bit ZX Spectrum
beeper engines (Phaser1, Octode, Savage, Tritone, ...). Music is authored in a
GUI tracker (Beepola, 1tracker, Bintracker) and *compiled* to a binary the
engine plays. This file is the transcription you type into the tracker.

TARGET ENGINE : Tritone  (3 tone channels + drums; 8 pulse widths, 12 samples)
                — matches the engine named in Design.md.
TOOL          : Beepola (Win, runs under Wine) or 1tracker. Choose the Tritone
                engine, enter the pattern below, export .tap / raw player.

SOURCE NOTES / ARRANGEMENT DECISIONS
------------------------------------
* Meter corrected to 4/4. Design.md says "M:2/4" but all three voices only sum
  correctly as 4/4 (8 eighth-notes per bar). Each bar below = 16 rows of 1/16.
* Key: G dorian (Gdor) => B is B-flat, E is E-flat throughout.
  In the tracker enter the enharmonic sharps:  Bb = A#,  Eb = D#.
* Octave map (ABC -> tracker): "C," = octave 3, "C" = octave 4, "c" = octave 5.
  Bass sits in octave 3, harmony/lead in octaves 4-5.
* Ties are realised as a single attack held across rows (no retrigger).
* Rests are an explicit key-off (OFF), then sustain.

TEMPO
-----
4/4, rousing march. Row = 1/16 note. Aim ~140 BPM quarter:
  row ≈ 0.107 s ≈ 5 frames/row  (set Tritone/Beepola "speed" = 5).
The whole A-section is 9 bars (144 rows); set the title screen to LOOP it.

NOTATION
--------
Columns: CH1 = Lead, CH2 = Harmony, CH3 = Bass.
A note name = attack on that row; "." = let the previous note ring (sustain);
"OFF" = key-off (silence). Durations are given in rows (1 row = 1/16).
Flats shown musically; tracker entry uses the # enharmonic noted above.
